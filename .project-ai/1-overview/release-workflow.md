# RELEASE WORKFLOW

## 1. Prerequisites
- Đảm bảo mã nguồn đã được kiểm thử và không có lỗi.
- Đã cập nhật version theo chuẩn SemVer (Semantic Versioning).
- Ghi log vào `system_map.md` và `decision-log.md`.

## 2. Release Steps
1. Đánh tag git phiên bản mới: `git tag vX.Y.Z`
2. Push lên remote: `git push origin vX.Y.Z`
